# SMART HOME

SMART HOME — frontend-проект одностраничного сайта компании по внедрению технологий умного дома.

Дизайн проекта разработан мной в Figma, после чего начата реализация интерфейса на HTML, CSS и JavaScript.

## Demo

https://prprlo.github.io/smart-home/

## Реализовано

- desktop-версия основных секций сайта;
- фиксированная навигация;
- Hero Section;
- блок «Возможности»;
- блок «Сценарии»;
- блок «Этапы работы»;
- первый экран расчёта стоимости;
- блок «О нас»;
- блок «Контакты»;
- Footer;
- модальное окно консультации;
- открытие и закрытие модального окна на JavaScript;
- валидация ФИО, телефона и e-mail;
- отображение ошибок в форме.
