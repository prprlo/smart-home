# SMART HOME

SMART HOME — одностраничный сайт компании по внедрению технологий умного дома.

Дизайн сайта разработан мной в Figma и реализован на HTML, CSS и JavaScript без использования фреймворков.

## Demo

https://prprlo.github.io/smart-home/

## Реализовано

- desktop-версия сайта по собственному макету Figma;
- фиксированная навигация и якорные переходы между секциями;
- интерактивный блок «Возможности» с переключением категорий;
- блок сценариев использования умного дома;
- блок этапов работы;
- многошаговый калькулятор стоимости;
- выбор параметров и сохранение данных между шагами калькулятора;
- форма отправки заявки;
- модальное окно консультации;
- валидация имени, телефона и e-mail;
- отображение ошибок при некорректном заполнении форм;
- экран успешной отправки;
- плавающий блок быстрых контактов;
- секции «О нас» и «Контакты»;
- Footer.
